# Audio recordings

Drop one MP3 per titik here, named to match the `audio` field in each
`content/titik/<slug>.md` file:

- `tabawan.mp3`
- `tarirai.mp3`
- `limbayan.mp3`
- `lellang.mp3`
- `senai-senai.mp3`

Until a real recording is added, the audio player on each titik page shows an empty
player — that's expected. Recordings should be cleared for sharing with the Sulimbag
Jawtee group and credited.
