# Resources

Place downloadable files here. The Resources page reads its listings from
`content/resources.json`.

- `TitikLab Pamhplet.pdf` — the two-page Malay-language TitikLab learning pamphlet.

To add a resource, upload its file here and add an entry to `content/resources.json`.
Include English and Malay titles, descriptions, and button labels. Use a public
URL such as `/media/resources/TitikLab%20Pamhplet.pdf` for `href`.
